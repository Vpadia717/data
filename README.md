# 1. Introduction

This guide is for selling **handmade crochet products online**.

The products may be:

* Crochet Hair Ties
* Crochet Scrunchies
* Crochet Flowers
* Crochet Bag Charms
* Crochet Keychains
* Crochet Phone Charms
* Crochet Dolls
* Crochet Hanging Decorations
* Handmade Accessories
* Small Crochet Gift Items

The main goal is:

> **Select the correct category → upload a clean product image → enter accurate product information → complete pricing/tax/package details → submit → fix QC issues → make the listing live.**

---

# 2. Products Covered

This guide mainly covers these four product types:

| Product      | Primary Purpose                                          |
| ------------ | -------------------------------------------------------- |
| Hair Tie     | Hair accessory                                           |
| Bag Charm    | Bag/accessory decoration                                 |
| Phone Charm  | Mobile phone accessory                                   |
| Crochet Doll | Hanging decoration / charm / toy depending on actual use |

---

# 3. Golden Rule — Choose the Correct Primary Use

This is the most important rule.

A crochet product can sometimes be used in multiple ways.

For example:

> One crochet flower can be used as a Hair Tie, Bag Charm and Phone Charm.

Do **not** automatically put the same listing into a random category.

Instead ask:

### Question:

**"What is the customer mainly buying this product for?"**

---

## Example

### If customer buys it for hair:

**Hair Tie**

Category:

> Hair Accessories

---

### If customer buys it for a bag:

**Bag Charm**

Category:

> Bag Charm / Keychain

---

### If customer buys it for mobile:

**Phone Charm**

Category:

> Phone Charm

---

### If customer buys it as decoration:

**Decorative Hanging**

Category:

> Home Decor / Hanging Decoration

---

```text
Elastic / Metal Ring / Lobster Clasp
```

Do not claim:

```text

```

If you use acrylic yarn:

```text

```

If you use mixed yarn:

```text
Yarn / Mixed Fibre
```

Use the closest truthful option provided by the marketplace.

# 17. Weight Details

You may need two different weights:

### Product Weight

Weight of the product itself.

Example:

```text
Product Weight:
15 g
```

### Package Weight

Weight after packaging.

Example:

```text
Package Weight:
25 g
```

Do not enter the same value automatically.

Use an actual weighing scale.

# 18. Package Details

Measure the final shipping package.

```text

Package Width: 10 cm
```

Flipkart's listing documentation includes package dimensions and package weight as listing data, with dimensions specified in centimetres and weight in kilograms in its API model.

# 19. Pricing

Calculate the real product cost first.

Example:

```text
Yarn Cost             ₹25
Elastic/Hook Cost     ₹5
Labour                ₹30
Packaging             ₹10
Other Cost            ₹5
--------------------------------
Total Cost            ₹75
```

Then calculate marketplace-related costs and desired profit.

Do not simply copy a competitor's price.

---

# 20. MRP

MRP should be set according to applicable Indian pricing/legal requirements.

Do not create an artificially inflated MRP just to show a large discount.

Example:

```text
MRP: ₹299
Selling Price: ₹149
```

Only use pricing that is genuinely compliant with applicable rules.

```text
Wrong dimensions
```
